# Saarthi Companion App — Plan

## Purpose
The companion app will help users configure Saarthi and access journey-related assistance.

## Planned Features
- Voice-based destination input
- Journey and route information
- Spoken guidance preferences
- Optional vibration and audio settings
- Device connection and battery status
- Start, pause, and stop navigation
- Accessible interface with clear labels and screen-reader support

## Development Status
These are proposed features. The companion app and its navigation capabilities are not yet implemented.

## Development Approach
1. Finalize the current Python camera and speech prototype.
2. Define the app screens and user workflow.
3. Build a basic accessible interface.
4. Connect the app to the prototype.
5. Investigate GPS, mapping, and public-transit integration.
6. Test usability and reliability before real-world deployment.

## Safety
Saarthi is intended to supplement, not replace, a conventional white cane or established mobility techniques.
